## Design reference

Color values in the default theme correspond to the color definitions of the Beamer theme `beamerthemehsrm` (Copyright (c) 2013-2014 Benjamin Weiss, GNU General Public License). Only the numeric values are used; no code from that theme is included in this repository. The theme names "Singapore" and "seagull" are standard Beamer theme names and are used only to describe the look.
